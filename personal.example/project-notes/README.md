# project-notes (personal, private)

Your own notes per project, one file each: `<key>.md`, where the key is the project's remote repository name, else its
folder name. `~/.claude/project-notes` links here (scripts/install.sh), so a note is written as
`~/.claude/project-notes/<key>.md`.

A note says how the global setup combines with that project's own setup: commands, conventions and facts that are true
for you there. Notes everyone should get live in the core repo's `home/project-notes/` instead. The project's own
committed files never mention these notes and are never edited for them.
