# ui-check/test

- `smoke.test.mjs` - end-to-end smoke test of compare and responsive against static fixtures, and the drawn font of the card title (Inter web font loaded; `card.html?font=absent` asks for a family no machine has, so a fallback is drawn and compare fails), a static SemiBold face that must pass (`fixtures/fonts/static-face.html`) and text deeper than two levels, in fields, a shadow root and generated content (`fixtures/fonts/deep-text.html`).
- `figma-diff-decisions.test.mjs` - browser-free tests for the `figma-diff --decisions` file: a written reason of 15+ characters, no owner field needed (an old one is not read), the row takes the entry's class and reason.
- `spec.test.mjs` - unit checks for flattenSpec, compareElements (the drawn-font rule included), alignColumns and the report cap (no browser needed).
- `units.test.mjs` - browser-free unit tests for colour parsing, measurement, pixel gate, cache/args validation and CLI exit-2 mapping.
- `steps.test.mjs` - browser-free tests for steps validation/runner, the `--steps`/`--bypass-csp` flags and the openPage bypass wiring (default off).
- `context.test.mjs` - browser-free tests for the context flags, their validation, the openPage wiring (stub browser) and the `bidi-field` detection.
- `batch.test.mjs` - browser-free tests for the states-file schema, `--only`, result records and the results.json/summary.md writer.
- `locale-browser.test.mjs` - Chromium tests (need `UI_CHECK_PROJECT`): bidi-field, `--expect-dir`, storage, locale, colour scheme, cookie, `batch` over two or more states.
- `fixtures/` - static HTML and JSON inputs (card, wide, frame, map, autofocus, rtl, rtl-ok, ltr, lang, switch) used by the smoke and determinism tests.
- `fixtures/fonts/` - `static-face.html` and `deep-text.html` (drawn-font pages); `inter-semibold-static.woff`, the subset below with the names a static SemiBold file ships with (fontTools: name ID 1 and 4 `Inter SemiBold`, 2 `Regular`, 6 `Inter-SemiBold`, 16 `Inter`, 17 `SemiBold`); `inter-600-ascii.woff`, Inter (SIL Open Font License, `OFL.txt` beside it) from google/fonts `ofl/inter/Inter[opsz,wght].ttf`, made with fontTools: `fonttools varLib.instancer Inter[opsz,wght].ttf wght=600 opsz=14 -o inter600.ttf`, then `fonttools subset inter600.ttf --unicodes=U+0020-007E --layout-features='' --flavor=woff --output-file=inter-600-ascii.woff`. It makes the card title draw in Inter on every machine, with or without Inter installed.
- `determinism.test.mjs` - launch args and autofocus step (browser-free), plus CPU-raster and autofocus checks in Chromium (need `UI_CHECK_PROJECT`).
- `rendered-checks.test.mjs` - browser-free tests for the pure decisions behind `raw-i18n-key`, `focus-indicator`, `rtl-physical-align` and `tap-target`.
- `focus-ring-capture.test.mjs` - browser-free tests for the focus-ring width: the measure (outline, `outline: none` with a box-shadow ring, glow, always-on shadow), `walkFocus` carrying it, and the `focus-ring-width` hint reaching report.md and report.json.
- `steps-diagnostics.test.mjs` - browser-free tests for the `focus` check and the "what covers the target" click message.
- `playwright-resolve.test.mjs` - browser-free tests for the Playwright lookup order and its error message (fake packages in temp folders).
- `batch-schedule.test.mjs` - browser-free tests for `--jobs`, the parallel/serial split, the pool, the progress line and `--resume`.
- `rendered-browser.test.mjs`, `batch-parallel.test.mjs` - Chromium tests (need `UI_CHECK_PROJECT`) for the above on local fixtures.
- `ltr-values.test.mjs` - browser-free tests for "only the typed value is left to right": `bidi-placeholder`, the three text hints, `same-as-default?` with its batch pass, the `sameInAllLocales` states key.
- `ltr-values-browser.test.mjs` - Chromium tests (need `UI_CHECK_PROJECT`) for the same on the `ltr-value-*.html`, `ltr-run.html`, `untranslated.html` and `same-*.html` fixtures, and for the probe leaving the page untouched.
- `ledger-states-golden.test.mjs` - browser-free golden test of the pixel path: ledger `states` rows, comparator, `compareRounds`, `compareReference`, their tables and the batch exit code on a fixed fixture equal the output taken from BASE 388ed5e4; any change there fails it.
- `same-run.test.mjs` - `run --same`: browser-free verdicts on pngjs fixtures (identical, equal, changed, a 1-level grey change, new, missing, a tampered capture: edited hash, path out of the folder, file or folder link, swapped bytes; a refused base: no head or this run's head; new finding id, more page errors, other renderer, empty), ledger states with a hand-edited hash, the ledger `captures` and `root`, old ledgers, the page-error watcher, and the `--same` exit 2 for a bad path, this run's own `--out` (direct, link, letter case) and a refused head; one Chromium case (needs `UI_CHECK_PROJECT`) runs `run` twice on `fixtures/card.html` in a second git worktree, then on an edited copy that throws.
- `isolated-env.mjs` - helper for the browser-free unit files below: a fresh short temp folder as `HOME`, `USERPROFILE` and `TMPDIR` per test (so the Figma cache root `~/.cache/figma` is never the real one), `FIGMA_TOKEN` unset, and the env, global `fetch` and mocks restored after each test.
- `first-paint.test.mjs` - browser-free tests for the first-paint constants, `frameLabel`, every `judgeFrames` verdict and violation (overflow, timeout, final frame, frame order, layout shift and its 20 ms tolerance) and the `samplerScript` source run against a stub page.
- `attribution.test.mjs` - browser-free tests for `textScopeBoxes`, the leftover colour metric, each attribution class (accepted, text anti-aliasing, flagged text at the 20 px boundary, graphic, other), paint order, clusters and `acceptedBox` on in-memory pngjs images.
- `attribution-records.test.mjs` - browser-free tests for `acceptanceContext`, `attributeRecords` (record filter, recount gate, default and strict rules, size mismatch, matrix acceptances, crops), `formatAttribution`, `writeAttribution` and `attributeStrict` on a temp cache folder.
- `crops.test.mjs` - browser-free tests for `cropTiles` (margin clipped at the edge, exact tiles of a region over 2,576 px) and `writeCrops` on small PNGs.
- `tolerances.test.mjs` - the tolerance tables are frozen and hold the values the docs name (odiff threshold 0.1, 0.5 % gate, responsive widths, 24 px target).
- `figma-api.test.mjs` - the Figma REST client with a stubbed `fetch`: no token is exit 2 before any call, the token only in the `X-Figma-Token` header and never in an error, one call for many ids in the asked order, URL-encoded ids, missing nodes and images.
- `figma-refresh-pull.test.mjs` - figma-refresh `compareEntry` (new, unchanged, changed by spec or baseline bytes), figma-pull `fetchTargets` (one nodes and one images call, hidden and skipped targets, meta) and a refresh run that leaves the cache as it was, with `fetch` stubbed and a temp `HOME`.
