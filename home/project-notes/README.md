# project-notes (personal layer, private)

Per-project instructions that use this personal setup (global skills, agents, hooks). Linked to
`~/.claude/project-notes` by `scripts/install.sh`. Each project gets a git-ignored `CLAUDE.local.md` with one line:

    @~/.claude/project-notes/<project>.md

The project's own committed config (CLAUDE.md, AGENTS.md, `.claude/`) stays complete without this folder and never
mentions it. Write here only how *my* global skills and agents combine with that project's own setup.
